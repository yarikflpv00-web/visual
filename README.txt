============================================================
  DONATIL VISUALS 2.4.1 - исходники мода (Fabric)
============================================================

  Это НАСТОЯЩИЙ мод. Меню модулей открывается на RIGHT SHIFT,
  закрывается той же клавишей. Все модули - чисто визуальные:
  они только рисуют на экране и не шлют серверу ни пакета.

════════════════════════════════════════════════════════════
  ПУТЬ 1: ОБЛАЧНАЯ СБОРКА - НИЧЕГО НЕ СТАВИТСЯ НА КОМП
  (не нужны ни IntelliJ IDEA, ни Gradle, ни JDK)
════════════════════════════════════════════════════════════

  Всё происходит в браузере на бесплатном GitHub Actions:

    1. Зайди на github.com -> Sign up (бесплатно, 2 минуты).
    2. Нажми плюсик справа сверху -> New repository,
       придумай имя (например, donatil-visuals) -> Create.
    3. На странице пустого репозитория жми
       'uploading an existing file'.
    4. Распакуй этот .zip и перетащи ВСЕ файлы из папки
       прямо в окно браузера (папки src и .github тоже!).
       Важно: папка .github с файлом сборки обязана попасть
       в репозиторий — без неё облако не поймёт, что делать.
    5. Commit changes.
    6. Открой вкладку Actions -> разреши workflows
       (зелёная кнопка 'I understand my workflows...').
    7. Подожди 2-4 минуты, пока запуск получит зелёную
       галочку. Открой его -> внизу блок Artifacts ->
       скачай donatil-visuals-jar.
    8. Внутри архива лежит ГОТОВЫЙ donatil-visuals-2.4.1.jar
       -> кидай в .minecraft/mods.

════════════════════════════════════════════════════════════
  ПУТЬ 2: ЛОКАЛЬНО (если захочешь когда-нибудь)
════════════════════════════════════════════════════════════

    1. Установи JDK 21 (adoptium.net).
    2. Открой папку в IntelliJ IDEA Community -> дождись
       Gradle-синхронизации -> Tasks -> build -> build.
    либо в консоли: gradle wrapper && gradlew build
    3. Забирай jar из build/libs/.

  ── КАК ПОСТАВИТЬ МОД ────────────────────────────────────

    1. Установи Fabric Loader под 1.21.1 (fabricmc.net).
    2. Скачай Fabric API и положи в .minecraft/mods.
    3. Положи туда же donatil-visuals-2.4.1.jar.
    4. Запусти профиль Fabric. В игре - RIGHT SHIFT.

  ── СТРУКТУРА ПРОЕКТА ────────────────────────────────────

    DonatilVisuals.java   точка входа, бинды клавиш, цикл
    ui/ClickGuiScreen     меню на правый шифт
    modules/              ядро модулей
    modules/visual/       FPS, Keystrokes, Fullbright, Zoom
    .github/workflows/    облачная сборка (GitHub Actions)
